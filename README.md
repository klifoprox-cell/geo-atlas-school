# Мир рядом — школьный географический атлас

Отдельный учебный проект для 6 класса на русском языке: поиск объектов и тренировка «Найди на карте» поверх подробной физической карты.

## Скачать и открыть

1. Нажмите **Code → Download ZIP** на странице репозитория.
2. Распакуйте архив целиком.
3. Откройте **index.html** в современном браузере.

Карта, библиотеки и геоданные находятся в проекте. Основные функции работают без интернета; внешние ссылки на источники требуют подключения. Сохранение прогресса при открытии локального файла зависит от настроек браузера.

Для локального сервера с установленным Node.js:

```sh
npm start
```

Затем откройте http://127.0.0.1:4173. Установка дополнительных пакетов не нужна. Проект также можно разместить на статическом хостинге, включая GitHub Pages.

## Возможности

- 58 объектов: 6 материков, 5 океанов, 12 морей, 10 островов и архипелагов, 9 полуостровов, 5 рек, 7 заливов, 4 пролива.
- Русские названия, синонимы, е/ё, сокращения «о.» и «п-ов» и некоторые опечатки в поиске.
- Приближение и крупная подпись найденного места, включая объекты без печатной подписи на подложке.
- Виды «Как в классе» и «Простая».
- До пяти заданий в тренировке, подсказки, показ ответа и итог.
- На школьной карте печатные названия сохраняются; дополнительная подсветка появляется после ответа.
- Прогресс хранится в браузере на текущем устройстве и не синхронизируется между устройствами.
- Компоновка для компьютера и телефона, масштабирование, перемещение и клавиатура.

## Файлы

| Файл | Назначение |
| --- | --- |
| `index.html` | Разметка |
| `style.css` | Оформление и мобильная компоновка |
| `app.js` | Карта, карточки и тренировка |
| `core.js` | Категории, поиск и геометрические функции |
| `atlas-data.js` | Каталог и геометрии объектов |
| `classroom-map.js` | Совмещение подписей со школьной картой |
| `sources.json` | Источники геоданных и контрольные суммы |
| `classroom-source.json` | Источник изображения и сведения о совмещении |
| `classroom.jpg` | Школьная физическая карта |
| `d3.min.js`, `d3-geo-projection.min.js` | Локальные библиотеки D3 |

Запись каталога: `id`, `name`, `kind`, `aliases`, `where`, `fact`, `hint`, `point`, `geometry`, `source`. Для расширения нужны проверенные геоданные. Не рисуйте произвольные географические границы.

## Источники и точность

Геоданные: [Natural Earth](https://www.naturalearthdata.com/), общественное достояние. Отдельные справочные точки: Wikidata и Marine Regions; конкретные ссылки сохранены в данных и карточках.

Школьная подложка: [физическая карта с 1maps.ru](https://1maps.ru/wp-content/uploads/2022/12/fizik_karta_mira.jpg), предоставленная пользователем как образец карты из класса. Права на стороннее изображение сохраняются за его правообладателями. Подробности: `THIRD_PARTY.txt`.

Геопривязка школьного изображения обзорная. Метки показывают положение, а не точные границы объектов. Проверка нажатий использует обобщённую геометрию с учебным допуском. Границы Саргассова моря определяют подвижные течения. В наборе принята модель шести материков и пяти океанов.

## Проверка

```sh
npm test
```

Проверяются объекты, русские названия и синонимы, ссылки на источники, проекции, попадания в объекты и синтаксис. Сборка не требуется.
